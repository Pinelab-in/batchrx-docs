Offline billing and sync

What offline billing gives you

Section titled “What offline billing gives you”

A registered terminal can make sales when the internet or server is unreachable. Each offline sale gets its real, final invoice number immediately and is sent to the server automatically once the connection is back.

Register this computer

Section titled “Register this computer”
  1. Open Sync.
  2. Under This device:
    • If a terminal has been assigned to you, click Set up this device.
    • Otherwise type a Terminal label (e.g. Front counter) and click Register this device.
  3. The page shows a Registered badge and the terminal’s code.

Use Register a different terminal instead if the assigned one is not the right counter.

Billing offline

Section titled “Billing offline”

Make sales exactly as normal. The sale dialog shows a Billing offline badge and says prices, batches and GST are worked out on this device.

Caution

An unregistered computer cannot bill offline — it shows a warning telling you to register from the Sync tab. Register every counter computer in advance, while it still has a connection.

Sync status

Section titled “Sync status”

Under Sync status you see Online/Offline, how many sales are pending sync, and when it last synced.

  • Sync now forces a sync immediately.
  • Reset local data wipes this device’s local copy and re-downloads it. Use it only if the device is stuck out of sync even after Sync now.

Terminals and failed syncs

Section titled “Terminals and failed syncs”
  • Terminals lists every registered terminal: label, online status, app version, last seen and who it is assigned to.
  • Sales that failed to sync lists any sale the server rejected, so you can see which one needs attention.

Network setup

Section titled “Network setup”

A computer must be on the pharmacy’s private network to reach the server. Owners and managers can do this from Sync → Network with a Connection key. See Signing in.
