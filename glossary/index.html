Glossary

Base unit — the smallest unit you sell (tablet, ml). Quantities are always in base units.

Batch — one lot of an item, with its own batch number, expiry and prices.

Credit note — the document created by a return.

FEFO — First Expiry, First Out. Stock is sold from the batch expiring soonest.

GSTIN — a business’s GST registration number.

HSN code — the tax classification code for a product.

MRP — maximum retail price printed on the pack.

PTR — price to retailer.

Schedule class — the drug’s regulatory category: G, H, H1, X or OTC. H1 and X need patient and prescriber details.

Terminal — a billing computer registered to bill offline.

Voucher — any financial record: a sale, purchase or credit note.
